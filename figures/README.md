# Figures

Sources for the manuscript figures that are reproducible from this public repository.

## Figure 1 — Eight-step clinical reasoning chain

- `figure_1_reasoning_chain.tex` — self-contained TikZ **source** (standalone document).
- `figure_1_reasoning_chain.pdf` — the compiled figure (tightly cropped).

This is a conceptual schematic (not data-driven), so it is reproduced directly
from LaTeX/TikZ. Rebuild with either:

```bash
latexmk -pdf figure_1_reasoning_chain.tex
# or
pdflatex figure_1_reasoning_chain.tex
```

Requires a system LaTeX distribution with TikZ (e.g. `texlive-latex-extra`); see
the repository README's *External LaTeX Requirements*.

## Figures 2–5 — Case profiles and radar plots

These are **data-driven** and are generated by the subject pipeline from the
blinded dataset, not stored here. Reproduce them with:

```bash
python scripts/neuropsych_subj_pipeline.py subj_001 subj_048
```

The multi-panel and radar plots are written to
`output_subj/subj_001/` (Figures 2–3) and `output_subj/subj_048/` (Figures 4–5).
